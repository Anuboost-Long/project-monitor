# Project Monitor — Icon and Logo Creative Brief

## What the application is

Project Monitor is a desktop operations desk for developers. It lets a user sync local software projects, discover their package scripts, run scripts or custom terminal commands, and watch several projects at the same time in a configurable wall of live terminal panels.

The application also captures console errors, keeps a local activity history, and can send structured error reports to a configured webhook. Its central idea is **one calm control surface for observing and operating many local projects**.

Key concepts the identity may represent:

- Multiple projects observed from one place
- A wall or grid of live terminal panels
- Terminal commands and continuous output
- Activity, signals, and error detection
- Local developer tooling rather than cloud infrastructure
- Order, visibility, and operational confidence

The product should feel like a focused developer instrument: technical, capable, precise, calm, and dependable. It should not feel playful, corporate, medical, or like a generic analytics dashboard.

## Original visual character

The interface uses a restrained operations-console style:

- Monospaced `Kode Mono` typography
- Flat, geometric surfaces with fine borders
- A subtle square grid behind the workspace
- Warm off-white working surfaces
- A very dark green-black sidebar and terminal
- Burnt orange used sparingly for actions, focus, and important signals
- Muted gray-green supporting text
- Small amounts of soft green for healthy or ready states

The icon should inherit this restraint. Prefer a strong silhouette, deliberate geometry, and one clear visual idea over several literal symbols combined together.

Recommended logo balance:

- Use `#E4582B` as the distinctive accent, not as a full multicolor background by default.
- Use `#17201D`, `#18211E`, or `#101714` for the main silhouette.
- Use `#F4F2EB` for negative space or a light-background variant.
- Reserve `#79B991` for a small ready/status signal if the concept truly needs it.
- Avoid gradients unless they are extremely subtle. The original identity is primarily flat color.

## Suggested icon direction

Create an abstract **monitor wall** symbol: a compact arrangement of terminal panels or project windows unified into one clear mark. A small command line, pulse, or active signal may pass through the panels to communicate live monitoring.

The symbol should:

- Read clearly at macOS dock and small toolbar sizes
- Work inside a square application-icon canvas
- Remain recognizable in one color
- Use simple geometric forms and controlled negative space
- Feel balanced on both the warm paper background and the dark sidebar
- Suggest monitoring and terminals without becoming a literal screenshot

Possible visual ingredients, used selectively:

- A two-by-two or asymmetric grid of terminal panes
- A single command prompt angle or short cursor line
- One orange active pane, scan line, or signal point
- Connected panels that imply several projects becoming one workspace
- A subtle `P` or `PM` monogram only if it emerges naturally from the geometry

## Avoid

- Generic eye, shield, magnifying-glass, cloud, or server-stack icons
- Medical monitoring imagery such as a heart or ECG line
- Overly literal computer-monitor illustrations
- Neon cyberpunk styling
- Glossy 3D rendering, glassmorphism, heavy shadows, or complex gradients
- Cute mascots, rounded cartoon shapes, or excessive detail
- Using purple or bright green as the primary identity color
- Tiny terminal text that disappears at application-icon size

## Ready-to-use generation prompt

> Design a distinctive application icon and logo mark for **Project Monitor**, a desktop developer operations tool that syncs local software projects, runs scripts and terminal commands, displays multiple live terminals in a configurable monitor wall, captures console errors, and sends structured error reports to webhooks. Create a restrained geometric symbol based on a unified wall or grid of terminal panels, with one subtle active command, scan, or signal element. The mark should communicate several projects observed and controlled from one calm workspace. Use the original palette: burnt orange `#E4582B` as the main accent, near-black green `#17201D` or `#101714` for the primary form, and warm paper `#F4F2EB` for negative space. Optional ready-state green is `#79B991` and should be used sparingly. Use flat shapes, precise geometry, fine visual rhythm, strong negative space, and a clear silhouette that remains legible at 16–32 px and works in a square macOS application-icon canvas. The personality is technical, focused, dependable, premium, and quietly operational. Avoid generic eyes, shields, clouds, server stacks, medical heartbeat imagery, cute mascots, neon cyberpunk effects, glossy 3D, heavy shadows, and complicated gradients. Provide light-background, dark-background, monochrome, and app-icon variants.
